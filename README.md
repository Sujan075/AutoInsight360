# AutoInsight360

Automotive Customer 360 Intelligence Agent.

An AI-powered system that provides unified automotive
customer information and evidence-backed customer insights.

## Current Status
Phase 0 - Project Setup

## Core Features
- Customer 360 lookup
- Historical Customer Value
- Vehicle information
- Loyalty history
- Service history
- AI-powered customer insights
- Natural language querying
- Security guardrails
- Audit logging

## Technology Stack
- Python 3.13
- FastAPI
- Uvicorn
- SQLite
- SQLAlchemy
- Ollama
- Llama 3.1
- HTML, CSS, JavaScript
